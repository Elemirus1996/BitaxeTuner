Privacy Policy

BitaxeTuner desktop app, server and website · last updated 27 Sep 2026

Summary

BitaxeTuner does not collect any data for the developers. There is no telemetry, no analytics, no user account and no cloud service operated by the project. All settings, history and tax records stay on your own computer, Raspberry Pi or server.

Network connections made by the software

The program only connects to the services below, and only for the stated purpose. Optional services are used only if you configure them.

DestinationPurposeWhen
Your miners in your local networkRead status, apply settings you confirmed, read logsAlways (core function)
api.github.com / github.comCheck for BitaxeTuner updates and miner firmware versions; download updates you startPeriodically; download only on request
mempool.spaceBitcoin network data (latest blocks, pools, difficulty – also for the optional e-paper price page), wallet balance lookupsNetwork data: when network features are used. Wallets: addresses you enter, or addresses detected from your miners' pool user only after you agree
api.blockchair.comWallet balances and incoming payments (e.g. BCH), for the tax overviewOnly for addresses you enter, or detected addresses after you agree
api.coingecko.comHistorical EUR exchange rates for the tax overview; current BTC/BCH price and 24-hour chart for the e-paper price pageTax: only if you use the tax features. Price page: only if you switch it on (off by default); no wallet or miner data is sent
api.awattar.de / .at, api.tibber.comElectricity pricesOnly if you select a price source (Tibber: with your own token)
ntfy.sh (or your ntfy server), api.telegram.org, discord.com, api.pushover.net, or your own webhook URLPush notifications you configuredOnly if you set up push notifications
Your smart plugs (Shelly) in your local networkRead power and energy (never switched)Only if you add smart plugs
Your own MQTT broker (e.g. Home Assistant)Publish miner valuesOnly if you enable MQTT

Wallet addresses you enter are sent to the respective explorer to look up balances. Addresses that BitaxeTuner detects in your miners' pool user (format address.worker) are only looked up after you agree once; you can withdraw this at any time in the settings. These third-party services have their own privacy policies. The BitaxeTuner server only accepts connections from private networks and is not meant to be exposed to the internet.

This website

The website is a static page hosted by GitHub Pages. It uses no cookies, no tracking and loads no content from third parties. GitHub may process technical access data (e.g. IP address) when delivering the page; see the GitHub Privacy Statement.

Contact

Questions: GitHub issues. Security issues: security policy.

Datenschutz

BitaxeTuner sammelt keine Daten für die Entwickler. Es gibt keine Telemetrie, keine Nutzungsstatistik, kein Konto und keinen Cloud-Dienst des Projekts. Einstellungen, Verlauf und Steuerdaten bleiben auf deinem PC, Raspberry Pi oder Server.

Das Programm verbindet sich nur mit den oben aufgeführten Diensten und nur zum jeweils genannten Zweck: mit deinen Minern im Heimnetz und deinen Smart Plugs (nur Messwerte lesen), mit GitHub (Updates, Firmware-Versionen), mempool.space und Blockchair (Netzwerkdaten, Wallet-Guthaben), CoinGecko (Euro-Kurse für die Steuerübersicht und – nur wenn eingeschaltet – die Kursseite des E-Papers), aWATTar/Tibber (Strompreis), ntfy/Telegram/Discord/Pushover oder deinem eigenen Webhook (Push) und deinem MQTT-Broker – die optionalen Dienste nur, wenn du sie einrichtest. Eingetragene Wallet-Adressen werden zur Abfrage an den jeweiligen Explorer übermittelt; Adressen, die BitaxeTuner im Pool-Benutzer deiner Miner erkennt (Format adresse.worker), erst nachdem du einmal zugestimmt hast – widerrufbar jederzeit in den Einstellungen; für diese Dienste gelten deren Datenschutzbestimmungen.

Diese Webseite verwendet keine Cookies, kein Tracking und lädt keine Inhalte von Drittanbietern. Sie wird über GitHub Pages bereitgestellt; GitHub verarbeitet dabei ggf. technische Zugriffsdaten (z. B. IP-Adresse), siehe Datenschutzerklärung von GitHub.
