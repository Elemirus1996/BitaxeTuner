Code Signing Policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only the Windows binaries built from this repository are signed: the installers BitaxeTuner-Setup-<version>.exe and BitaxeTuner-Server-Setup-<version>.exe and the program files BitaxeTuner.exe and BitaxeTuner.Server.exe they contain. No third-party or upstream binaries are signed with this certificate.

How releases are built

Every release is built by GitHub Actions (release.yml) from a version tag in the public repository. The build runs the test suite, publishes the binaries and attaches them together with SHA-256 checksums to the GitHub release. Signing requests are submitted only from this workflow.

Team roles

External contributions are accepted via pull requests and are reviewed before merging. Maintainers are required to use two-factor authentication on GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See the privacy policy for the list of services the program can connect to and when.
